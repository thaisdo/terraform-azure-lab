# Terraform Azure Lab

Small Infrastructure as Code project using Terraform and Microsoft Azure.

## Objective

This project is a practical laboratory to learn Terraform fundamentals
and provision Azure infrastructure using Infrastructure as Code.

## Technologies

- Terraform
- Microsoft Azure
- AzureRM Provider
- PowerShell

## Current infrastructure

- Azure Resource Group

## Terraform concepts practiced

- Providers
- Resources
- Variables
- Variable defaults
- terraform.tfvars
- Outputs
- Terraform State
- terraform plan
- terraform apply
- Resource replacement
- In-place updates
- Azure resource tagging
